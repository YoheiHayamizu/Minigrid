# Task: Step logic + collision resolution

## Description

Implement the `step(actions)` method with simultaneous action execution and collision resolution. This is the core game loop for multi-agent interaction.

## Acceptance Criteria
- [ ] `step(actions: dict[str, int])` accepts one action per active agent
- [ ] Rotation actions (left/right) are applied without conflict
- [ ] Forward movement uses two-pass collision resolution:
  - Intent pass: compute intended positions
  - Conflict pass: agents targeting same cell or swapping positions stay in place
  - Commit pass: apply non-conflicting moves
- [ ] Object interactions (pickup/drop/toggle) processed after movement, in agent index order
- [ ] If two agents try to pick up the same object, lower-index agent succeeds
- [ ] `Door.toggle` compatibility: temporarily set `self.carrying` to acting agent's object
- [ ] Per-agent terminated/truncated flags
- [ ] Agent stepping on Goal sets terminated=True, gets reward from `_reward(agent_name)`
- [ ] Agent stepping on Lava sets terminated=True, reward=0
- [ ] Truncation when `step_count >= max_steps` (applies to all remaining agents)
- [ ] Terminated/truncated agents removed from `self.agents` (PettingZoo convention)
- [ ] Returns `(observations, rewards, terminations, truncations, infos)` as dicts
- [ ] `_reward(agent_name)` is overridable by subclass (default: `1 - 0.9 * step_count/max_steps`)

Object interaction ordering:
```python
for agent_name in sorted(active_agents):  # deterministic order
    action = actions[agent_name]
    state = self.agent_states[agent_name]
    fwd_pos = state.front_pos
    fwd_cell = self.grid.get(*fwd_pos)

    if action == Actions.pickup:
        if fwd_cell and fwd_cell.can_pickup() and state.carrying is None:
            state.carrying = fwd_cell
            self.grid.set(*fwd_pos, None)
    elif action == Actions.drop:
        if state.carrying and not fwd_cell:
            self.grid.set(*fwd_pos, state.carrying)
            state.carrying = None
    elif action == Actions.toggle:
        if fwd_cell:
            # Compat shim for Door.toggle
            self.carrying = state.carrying
            fwd_cell.toggle(self, fwd_pos)
            self.carrying = None
```

Also check that forward cell is not occupied by another agent before allowing pickup/drop (agent in front blocks access to the cell's object).
