# Task: Agent state dataclass + package scaffold

## Description

Create the `minigrid/multigrid/` subpackage directory structure and the `AgentState` dataclass that encapsulates per-agent state. This is the foundation all other tasks build on.

## Acceptance Criteria
- [ ] `minigrid/multigrid/` package exists with proper `__init__.py`
- [ ] `minigrid/multigrid/envs/` subpackage exists with `__init__.py`
- [ ] `AgentState` dataclass is defined in `minigrid/multigrid/agent.py`
- [ ] `AgentState` has fields: `pos` (tuple[int,int]), `dir` (int), `color` (str), `carrying` (WorldObj | None), `terminated` (bool), `truncated` (bool)
- [ ] `AgentState` has helper properties: `dir_vec`, `front_pos`
- [ ] Default agent color palette is defined (red, blue, green, purple, yellow, grey)
- [ ] `from minigrid.multigrid import AgentState` works

## Technical Details

```python
@dataclass
class AgentState:
    pos: tuple[int, int] = (-1, -1)
    dir: int = 0
    color: str = "red"
    carrying: WorldObj | None = None
    terminated: bool = False
    truncated: bool = False

    @property
    def dir_vec(self) -> tuple[int, int]:
        return DIR_TO_VEC[self.dir]

    @property
    def front_pos(self) -> tuple[int, int]:
        return (self.pos[0] + self.dir_vec[0], self.pos[1] + self.dir_vec[1])

AGENT_COLORS = ["red", "blue", "green", "purple", "yellow", "grey"]
```
