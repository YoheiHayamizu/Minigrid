# Task: Example env: MultiGrid-DoorKey

## Description

Create a cooperative multi-agent environment where agents must work together. One agent picks up a key and unlocks/opens a door, while another agent passes through to reach the goal. Requires coordination between agents.

## Acceptance Criteria
- [ ] `MultiGridDoorKeyEnv` subclasses `MultiGridEnv`
- [ ] 2 agents by default (configurable)
- [ ] Grid has two rooms separated by a wall with a locked door
- [ ] One key placed in the first room
- [ ] Goal placed in the second room
- [ ] Any agent can pick up the key and unlock the door
- [ ] Any agent reaching the goal terminates the episode for all (cooperative)
- [ ] Both agents receive shared reward when goal is reached
- [ ] If max_steps exceeded, both agents get 0 reward
- [ ] Renderable in both modes

## Technical Details

```python
class MultiGridDoorKeyEnv(MultiGridEnv):
    def __init__(self, size=8, num_agents=2, max_steps=None, **kwargs):
        mission_space = MissionSpace(
            mission_func=lambda: "cooperate to unlock the door and reach the goal"
        )
        if max_steps is None:
            max_steps = 10 * size * size
        super().__init__(
            mission_space=mission_space,
            num_agents=num_agents,
            grid_size=size,
            max_steps=max_steps,
            **kwargs,
        )

    def _gen_grid(self, width, height):
        self.grid = Grid(width, height)
        self.grid.wall_rect(0, 0, width, height)

        # Vertical wall splitting the room
        split_x = width // 2
        self.grid.vert_wall(split_x, 0, height)

        # Locked door in the wall
        door_y = self._rand_int(1, height - 1)
        door = Door("yellow", is_locked=True)
        self.grid.set(split_x, door_y, door)

        # Key in the left room
        key = Key("yellow")
        self.place_obj(key, top=(1, 1), size=(split_x - 1, height - 2))

        # Goal in the right room
        goal = Goal()
        self.place_obj(goal, top=(split_x + 1, 1), size=(width - split_x - 2, height - 2))

        # Place all agents in the left room
        for i in range(self.num_agents):
            self.place_agent(i, top=(1, 1), size=(split_x - 1, height - 2))
```

Cooperative reward: override step to give both agents the reward when any agent reaches the goal.
