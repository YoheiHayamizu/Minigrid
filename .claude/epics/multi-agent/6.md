# Task: Multi-agent rendering

## Description

Implement rendering for multi-agent environments showing all agents as distinctly colored triangles on the grid. Support both "human" (pygame window) and "rgb_array" render modes.

## Acceptance Criteria
- [ ] `render()` shows all active agents as colored triangles on the full grid
- [ ] Each agent has a distinct color matching their `AgentState.color`
- [ ] Agent triangles rotate based on their direction (same as single-agent)
- [ ] "human" mode opens pygame window with grid + mission text
- [ ] "rgb_array" mode returns numpy RGB array
- [ ] Highlight mask shows union of all agents' visible cells (optional, configurable)
- [ ] `get_full_render()` works with multiple agents
- [ ] Rendering helper in `minigrid/multigrid/rendering.py`

## Technical Details

### Approach: overlay agent tiles on rendered grid

```python
def get_full_render(self, highlight, tile_size):
    # 1. Compute highlight mask (union of all agents' views)
    highlight_mask = np.zeros((self.width, self.height), dtype=bool)
    if highlight:
        for name, state in self.agent_states.items():
            if state.terminated or state.truncated:
                continue
            agent_highlight = self._compute_agent_highlight(state)
            highlight_mask |= agent_highlight

    # 2. Render grid WITHOUT any agents
    img = self.grid.render(tile_size, agent_pos=(-1, -1), agent_dir=None,
                           highlight_mask=highlight_mask if highlight else None)

    # 3. Overlay each agent's colored triangle
    for name, state in self.agent_states.items():
        if state.terminated or state.truncated:
            continue
        render_agent_tile(img, state.pos, state.dir, state.color, tile_size)

    return img
```

### Colored agent triangle rendering

```python
def render_agent_tile(img, pos, direction, color, tile_size):
    """Render a colored agent triangle onto an existing image."""
    # Create tile with just the agent triangle
    tile_img = np.zeros((tile_size, tile_size, 3), dtype=np.uint8)
    # Draw triangle with agent's color (not hardcoded red)
    tri_fn = point_in_triangle((0.12, 0.19), (0.87, 0.50), (0.12, 0.81))
    tri_fn = rotate_fn(tri_fn, cx=0.5, cy=0.5, theta=0.5 * math.pi * direction)

    # Use supersampling like Grid.render_tile
    subdivs = 3
    big = np.zeros((tile_size * subdivs, tile_size * subdivs, 3), dtype=np.uint8)
    fill_coords(big, tri_fn, COLORS[color])
    tile_img = downsample(big, subdivs)

    # Alpha-blend: only overwrite non-black pixels
    x, y = pos
    ymin, ymax = y * tile_size, (y + 1) * tile_size
    xmin, xmax = x * tile_size, (x + 1) * tile_size
    mask = tile_img.any(axis=2)
    img[ymin:ymax, xmin:xmax][mask] = tile_img[mask]
```
