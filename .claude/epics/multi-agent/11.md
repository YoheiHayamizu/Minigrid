# Task: Packaging + environment registration

## Description

Add PettingZoo as an optional dependency, register all multi-agent environments with Gymnasium, and ensure the package is installable and discoverable.

## Acceptance Criteria
- [ ] `pettingzoo>=1.24.0` added as optional extra in `pyproject.toml` under `[multigrid]`
- [ ] `pip install -e ".[multigrid]"` installs PettingZoo
- [ ] All 3 example envs registered with Gymnasium:
  - `MultiGrid-Empty-8x8-v0`
  - `MultiGrid-Empty-6x6-v0`
  - `MultiGrid-DoorKey-8x8-v0`
  - `MultiGrid-Adversarial-8x8-v0`
- [ ] `gymnasium.make("MultiGrid-Empty-8x8-v0")` works
- [ ] Registration is in `minigrid/multigrid/__init__.py` or a dedicated registration module
- [ ] `minigrid/__init__.py` conditionally imports multigrid registration (only if pettingzoo installed)
- [ ] Importing `minigrid` without PettingZoo installed still works (no import error)
- [ ] `from minigrid.multigrid import MultiGridEnv, AgentState` documented in module docstring

## Technical Details

### pyproject.toml changes
```toml
[project.optional-dependencies]
multigrid = ["pettingzoo>=1.24.0"]
testing = ["pytest", "pettingzoo[testing]>=1.24.0"]
```

### Registration in multigrid/__init__.py
```python
from gymnasium.envs.registration import register

def register_multigrid_envs():
    register(
        id="MultiGrid-Empty-8x8-v0",
        entry_point="minigrid.multigrid.envs:MultiGridEmptyEnv",
        kwargs={"size": 8, "num_agents": 2},
    )
    register(
        id="MultiGrid-Empty-6x6-v0",
        entry_point="minigrid.multigrid.envs:MultiGridEmptyEnv",
        kwargs={"size": 6, "num_agents": 2},
    )
    register(
        id="MultiGrid-DoorKey-8x8-v0",
        entry_point="minigrid.multigrid.envs:MultiGridDoorKeyEnv",
        kwargs={"size": 8, "num_agents": 2},
    )
    register(
        id="MultiGrid-Adversarial-8x8-v0",
        entry_point="minigrid.multigrid.envs:MultiGridAdversarialEnv",
        kwargs={"size": 8, "num_agents": 2},
    )
```

### Conditional import in minigrid/__init__.py
```python
try:
    from minigrid.multigrid import register_multigrid_envs
    register_multigrid_envs()
except ImportError:
    pass  # PettingZoo not installed, multigrid envs not available
```
