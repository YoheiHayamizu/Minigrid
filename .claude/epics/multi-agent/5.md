# Task: Observation generation (POMDP + MDP)

## Description

Implement per-agent observation generation supporting both POMDP (partial view) and MDP (full grid) modes. Other agents must appear as colored objects in observations.

## Acceptance Criteria
- [ ] `gen_obs(agent_name)` returns `{"image": ndarray, "direction": int, "mission": str}`
- [ ] POMDP mode (default): agent gets rotated partial view (agent_view_size x agent_view_size x 3)
- [ ] MDP mode (`full_obs=True`): agent gets full grid encoding (width x height x 3)
- [ ] Other agents appear in observations as type=10 (agent) with their color index
- [ ] Agents that are terminated/truncated do NOT appear in observations
- [ ] Visibility masking works (walls block line of sight in POMDP mode)
- [ ] `see_through_walls` option bypasses visibility masking
- [ ] Agent's carried object appears at agent position in their own partial view
- [ ] `gen_obs_grid(agent_name)` returns `(Grid, vis_mask)` for a specific agent

## Technical Details

### Placing agents in the grid for observation

Before encoding observations, temporarily place `AgentObj` instances in the grid at each agent's position, then remove them after encoding. `AgentObj` is a lightweight `WorldObj` subclass:

```python
class AgentObj(WorldObj):
    def __init__(self, color="red"):
        super().__init__("agent", color)

    def can_overlap(self):
        return False  # agents block each other

    def see_behind(self):
        return True

    def render(self, img):
        # Colored circle to distinguish from the triangle (which is the observer)
        fill_coords(img, point_in_circle(0.5, 0.5, 0.31), COLORS[self.color])
```

### POMDP observation flow (per agent):
1. Place all OTHER agents as `AgentObj` in the grid
2. Compute view extents using agent's pos/dir (`get_view_exts`)
3. Slice grid to get partial view
4. Rotate based on agent direction
5. Apply visibility masking (`process_vis`)
6. Place carried object at agent's position in view
7. Encode to numpy array
8. Remove `AgentObj` instances from grid

### MDP observation flow (per agent):
1. Place all OTHER agents as `AgentObj` in the grid
2. Encode full grid
3. Remove `AgentObj` instances from grid

### View computation
Port `get_view_exts()` and `get_view_coords()` from `MiniGridEnv` as standalone functions or methods that take `(agent_pos, agent_dir, view_size)` as parameters instead of reading from `self`.
