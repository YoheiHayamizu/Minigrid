# Task: Core MultiGridEnv base class

## Description

Implement the `MultiGridEnv` base class extending PettingZoo `ParallelEnv`. This task covers the constructor, `reset()`, PettingZoo required properties/methods, and ported helper utilities (placement, random). Step logic and observation generation are separate tasks.

## Acceptance Criteria
- [ ] `MultiGridEnv` extends `pettingzoo.ParallelEnv`
- [ ] Constructor accepts: `mission_space`, `num_agents`, `grid_size`/`width`/`height`, `max_steps`, `see_through_walls`, `agent_view_size`, `render_mode`, `full_obs`, `agent_colors`
- [ ] `possible_agents` returns `["agent_0", ..., "agent_{n-1}"]`
- [ ] `agents` returns list of currently active (non-terminated, non-truncated) agent names
- [ ] `observation_space(agent)` returns correct `spaces.Dict` (adapts shape based on `full_obs`)
- [ ] `action_space(agent)` returns `spaces.Discrete(7)`
- [ ] `reset(seed, options)` generates grid via `_gen_grid()`, places agents, returns `(obs_dict, info_dict)`
- [ ] `_gen_grid(width, height)` is abstract
- [ ] `place_agent(agent_index, ...)` places agent at empty position, avoiding other agents
- [ ] `place_obj()`, `put_obj()` ported from MiniGridEnv (reject positions occupied by any agent)
- [ ] Random utilities ported: `_rand_int`, `_rand_float`, `_rand_bool`, `_rand_elem`, `_rand_subset`, `_rand_color`, `_rand_pos`
- [ ] `self.agent_states` is an ordered dict `{name: AgentState}`
- [ ] `self.grid` is a `Grid` instance (reused from existing code)

## Technical Details

Key difference from `MiniGridEnv`: `place_obj` rejection must check against ALL agent positions, not just one. The `place_agent` helper updates the specific agent's state in `self.agent_states`.

`reset()` flow:
1. Call `super().reset()` for seeding
2. Initialize all agent states to defaults
3. Create fresh `Grid(width, height)`
4. Call `self._gen_grid(width, height)` (subclass fills grid + places agents)
5. Validate all agents are placed
6. Set `self.step_count = 0`
7. Generate and return per-agent observations

PettingZoo requires `observation_space` and `action_space` to be methods (not properties) that take an agent name.
