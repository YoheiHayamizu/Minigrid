# Task: Example env: MultiGrid-Empty

## Description

Create the simplest multi-agent environment: N agents in an empty room, each with their own colored goal. Agents must independently navigate to their assigned goal.

## Acceptance Criteria
- [ ] `MultiGridEmptyEnv` subclasses `MultiGridEnv`
- [ ] Configurable: `size` (grid size), `num_agents` (default 2)
- [ ] Each agent has a distinct colored goal placed at a random position
- [ ] Agent i's goal color matches agent i's color
- [ ] An agent is terminated when it reaches its own goal
- [ ] Episode ends when all agents reach their goals or max_steps
- [ ] Per-agent reward: `1 - 0.9 * (step_count / max_steps)` when reaching goal
- [ ] `_gen_grid` places walls, goals, and agents
- [ ] Works with 2, 3, and 4 agents
- [ ] Renderable in both modes

## Technical Details

```python
class MultiGridEmptyEnv(MultiGridEnv):
    def __init__(self, size=8, num_agents=2, max_steps=None, **kwargs):
        mission_space = MissionSpace(mission_func=lambda: "get to your goal")
        if max_steps is None:
            max_steps = 4 * size * size
        super().__init__(
            mission_space=mission_space,
            num_agents=num_agents,
            grid_size=size,
            max_steps=max_steps,
            **kwargs,
        )

    def _gen_grid(self, width, height):
        self.grid = Grid(width, height)
        self.grid.wall_rect(0, 0, width, height)

        # Place a colored goal for each agent
        for i in range(self.num_agents):
            color = self.agent_states[f"agent_{i}"].color
            goal = Goal(color)
            self.place_obj(goal)

        # Place agents at random positions
        for i in range(self.num_agents):
            self.place_agent(i)

    def step(self, actions):
        obs, rewards, terminations, truncations, infos = super().step(actions)
        # Check if each agent reached their colored goal
        for name, state in self.agent_states.items():
            cell = self.grid.get(*state.pos)
            if cell and cell.type == "goal" and cell.color == state.color:
                rewards[name] = self._reward(name)
                terminations[name] = True
        return obs, rewards, terminations, truncations, infos
```

Note: exact reward/termination logic may be integrated into base class step or handled in subclass override.
