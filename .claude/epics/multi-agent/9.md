# Task: Example env: MultiGrid-Adversarial

## Description

Create a competitive multi-agent environment where agents race to reach a single goal. The first agent to reach the goal gets a positive reward; all others get zero or negative reward.

## Acceptance Criteria
- [ ] `MultiGridAdversarialEnv` subclasses `MultiGridEnv`
- [ ] 2 agents by default (configurable)
- [ ] Single Goal placed in the grid
- [ ] First agent to reach the goal: reward = `1 - 0.9 * (step_count / max_steps)`, terminated
- [ ] Other agents: reward = 0, terminated (episode ends for all)
- [ ] Agents block each other's movement (can be used strategically)
- [ ] If max_steps exceeded, all agents get 0 reward
- [ ] Renderable in both modes

## Technical Details

```python
class MultiGridAdversarialEnv(MultiGridEnv):
    def __init__(self, size=8, num_agents=2, max_steps=None, **kwargs):
        mission_space = MissionSpace(
            mission_func=lambda: "race to the goal"
        )
        if max_steps is None:
            max_steps = 4 * size * size
        super().__init__(
            mission_space=mission_space,
            num_agents=num_agents,
            grid_size=size,
            max_steps=max_steps,
            **kwargs,
        )

    def _gen_grid(self, width, height):
        self.grid = Grid(width, height)
        self.grid.wall_rect(0, 0, width, height)

        # Single goal
        self.place_obj(Goal())

        # Place agents at random positions
        for i in range(self.num_agents):
            self.place_agent(i)
```

Override step to detect when any agent reaches the goal and end the episode for all agents.
